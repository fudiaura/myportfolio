# Personal Portfolio Website

A responsive, dark space-inspired portfolio made with HTML, CSS, and vanilla JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in your browser, or open the folder in VS Code and use Live Server.

## Personalize it
- In `index.html`, replace `Your Name`, the biography, project details, social links, and `your.email@example.com`.
- Replace the placeholder in the hero with your own photo. Search for `portrait-placeholder` in `index.html`; you can replace that block with:
  `<img src="assets/profile.jpg" alt="Your Name" class="profile-photo">`
  Then add `.profile-photo { width:100%; height:100%; object-fit:cover; }` to `style.css`.
- Update skill levels and certificate information to match your real experience.
- In `script.js`, replace `your.email@example.com` with your actual email. The form opens the visitor's email application; it does not store or send messages through a server.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styles, colors, animations
- `script.js` — mobile navigation, star animation, reveal effects, and contact form
